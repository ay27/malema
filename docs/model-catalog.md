# 支持的模型系列

检索日期 2026-11-25。当前收录 102 个模型系列、1,188 个标准公开型号及 2,509 个名称写法。

The desktop app normalizes model names before upload. The Worker applies the same catalog to incoming snapshots and public responses. The board uses the shared family assignments.

- A recognized public model keeps its standard name; common provider and dated aliases merge into it.
- A recognized family with an unknown or ambiguous model uses a fixed family bucket, such as `family:kimi`. The board displays “Kimi / Moonshot · other models”.
- An unknown or conflicting family uses `other`. Original route names, private prefixes and unknown version strings are never returned.
- This catalog is a dated coverage snapshot, not a promise to enumerate every future model. Unknown versions can still contribute to their family.

## Maintaining the catalog

`model-catalog.json` contains public model IDs and aliases. `model-families.json` contains the family labels, safe family aliases and the model-to-family assignments. Add only names present in a public provider catalog or a publisher’s public model card, and retain the source URL. Do not add any user’s private route names to either file or to tests.

Run `npm run check`, `npm test` in `cloudflare`, and `cargo test --locked` after updates. Shared examples in `model-normalization-cases.json` test Rust and TypeScript against the same expectations.

Migration `0003_public_model_names.sql` is frozen release history. It must not be regenerated when the catalog expands. Already-scrubbed unknown names stay anonymized; an updated app can reconstruct the new grouping by rescanning local history and submitting its full snapshot.

Catalog research used the [OpenRouter public model API](https://openrouter.ai/docs/api/api-reference/models/list-all-models-and-their-properties), publisher model lists, and public model metadata from their Hugging Face organizations. Text-generation models and models that accept text and reply with text are in scope; image/video/audio generation, embeddings and rerankers are excluded.
